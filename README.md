frictionless digital menu experience for smartphones and desktop browsers. Built with lightweight vanilla web standards for instant loading, zero external dependencies, and offline resilience.\n\n---\n\n## 🚀 Key Features\n\n- 📱 **Mobile-First Responsive Layout:** Fluid CSS grid and flexbox design adapting smoothly to any viewport.\n- 📲 **PWA Ready:** Includes Web App Manifest (`manifest.json`) and high-resolution icons allowing guests to install the menu directly to their mobile home screen.\n- 🏷️ **Dynamic Category Filtering:** Filter items by Traditional Pizzas, Specialty Pies, Appetizers, and Beverages.\n- ⚡ **Zero-Dependency Architecture:** Pure HTML5, modern CSS3 variables, and vanilla JavaScript for blazing fast load speeds.\n\n---\n\n## ⚡ Quick Start\n\nNo build tools or compilers required! Simply clone and open:\n\n```bash\n# 1. Clone repository\ngit clone https://github.com/amirthn6533/pizza-italia-menu.git\ncd pizza-italia-menu\n\n# 2. Open index.html in any browser:\n# On Windows:\nstart index.html\n# On macOS:\nopen index.html\n# On Linux:\nxdg-open index.html\n```\n\nOr serve locally:\n```bash\npython -m http.server 3000\n```\nThen visit `http://localhost:3000`.\n\n---\n\n## 📄 License\n\nThis project is licensed under the [MIT License](LICENSE).
